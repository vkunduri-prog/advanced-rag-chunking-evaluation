# Academic Context

## Project

**Title:** Chunking Policies in RAG  
**Institution:** Arizona State University  
**Type:** Collaborative academic project

This repository is my documentation-first portfolio version of the project. It explains the complete system architecture while clearly identifying the areas I worked on directly.

My work focused on:

- Text segmentation for contextual retrieval
- Context-description generation using `Llama-3.2-1B-Instruct`
- Construction and testing of context-enriched chunks
- Streamlit interface collaboration and workflow integration

The original project was completed as a team. This repository does not claim sole authorship of the full application or every chunking method.
